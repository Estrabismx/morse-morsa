Dictar con manipulador

Mantén presionado el botón: pulsación corta = punto, larga = raya. Haz una pausa para cerrar la letra y una pausa más larga para separar palabras. Lo que dictes se escribe y se traduce solo.

Alfabeto morse en español

Toca una tarjeta para escucharla o verla destellar. Punto = 1 tiempo, raya = 3 tiempos, separación entre letras = 3 tiempos y entre palabras = 7.
